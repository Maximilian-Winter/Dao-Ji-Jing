# Split Edition

These files partition the complete [道機經 - Dao Ji Jing.md](../%E9%81%93%E6%A9%9F%E7%B6%93%20-%20Dao%20Ji%20Jing.md) into its introductory material, five elemental volumes, and appendices.

- [Introduction](00-introduction.md)
- [Volume One: Metal Mechanism](01-metal-mechanism.md)
- [Volume Two: Wood Mechanism](02-wood-mechanism.md)
- [Volume Three: Water Mechanism](03-water-mechanism.md)
- [Volume Four: Fire Mechanism](04-fire-mechanism.md)
- [Volume Five: Earth Mechanism](05-earth-mechanism.md)
- [Appendices and Closing Seal](06-appendices.md)

The complete source document remains available at the repository root. The five volume files contain only their respective elemental volumes. Concatenating files `00` through `06` in filename order reproduces the complete 15,536-line source document without alteration.
